Engineered for High-Consequence, Zero-Egress Environments

Every layer of AirVault is purpose-built to eliminate cloud dependencies while delivering sub-second hybrid retrieval across terabytes of classified engineering manuals, schematics, and CAD packages.

1. Zero External Telemetry

Runs entirely on local hardware with Ed25519 asymmetric license keys and zero outbound network traffic. Container bridge networks enforce internal: true with no default gateway.

LICENSE VERIFICATIONEd25519 OFFLINE KEY

2. Layout-Aware Ingestion

Parses complex engineering PDFs, multi-column technical specs, and CAD drawing title blocks while retaining table structure via Docling & Surya OCR.

PARSER ENGINEDOCLING + SURYA OCR

3. Dual-Stage Hybrid Search

Combines Qdrant dense vector semantic search (BGE-Large) with OpenSearch BM25 sparse lexical search using Reciprocal Rank Fusion (RRF) for exact MIL-SPEC and part-number matching.

RETRIEVAL FUSIONQDRANT + BM25 (RRF k=60)

4. Attribute-Based Access Control (ABAC)

Integrated with Active Directory, LDAP, and CAC/PIV smartcards to enforce security clearance filtering down to individual document chunks prior to LLM context assembly.

IDENTITY ENFORCEMENTAD / LDAP / CAC PIV

5. High-Throughput Local Runtime

Powered by vLLM & NVIDIA Triton with PagedAttention, serving quantized models (Qwen 2.5 14B/72B, Llama 3.3 70B AWQ) on local GPUs (NVIDIA L40S, A100, H100).

INFERENCE ENGINEvLLM + TRITON AWQ

6. Cross-Encoder & BBox Grounding

Re-scores Top-30 candidates down to the Top-5 highest-confidence snippets using bge-reranker-large and binds every claim to verifiable PDF bounding boxes.
